## Genetic Programming and Evolutionary Machine Learning Symposium (GPEML)

### About the Symposium

The Genetic Programming and Evolutionary Machine Learning (GPEML) Symposium focuses on the cutting-edge theories and applications of Genetic Programming (GP) and Evolutionary Machine Learning (EML). With the rapid advancement of computational intelligence, GP and EML have demonstrated tremendous potential in automated program generation, feature engineering, explainable AI, evolutionary deep learning, and other emerging fields. The symposium gathers leading experts and scholars worldwide to discuss the latest research advances, key technologies, and practical applications of GP and EML.
